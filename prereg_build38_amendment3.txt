4. Rows. All are frozen-engine methods (lgc_bench/engine.py sha256 835f1933d9e5..., REGISTRY names):
   - LGC_RC_EGC (the method; "EGC"): the B5 cells b5_main_LGC_RC_EGC_{arch}_{NT,T}. Not re-run.
   - LGC_RC ("no ambient block"): CGBA circle chord in the autoencoder latent + residual coordinate.
   - LGC_RC_EGCI ("circle metric"): EGC with R ~ I (isotropic circle in the latent and ambient blocks), same SSIM
     gate, same doubling exploration.
   - LGC_RC_HT1000 ("naive switch"): LGC_RC for 1000 queries, then the engine's TtBA pixel stage (lgc_bench port of
     TtBA, DCT f = 4; not the official TtBA repository code) on the full perturbation.
   The 18 new cells are {LGC_RC, LGC_RC_EGCI, LGC_RC_HT1000} x {vgg19, resnet50, vit_b_32} x {non_targeted,
   targeted}, n = 200 each, output Results/e9_{METHOD}_{arch}_{NT|T}. Each command line is the B5 LGC_RC_EGC command
   line (run_b5_parallel.sh, cells main_LGC_RC_EGC_*) with only --methods and --out_dir changed: run_benchmark_33b.py
   (sha256 9c62820e5fafbac7e8c3f2cf3a688e3e6e7c53f3c5fc7f709ef5f34d17861873), --save_adv, the 8 checkpoints
   100 ... 10000, --max_queries 10000. The per-image seed depends only on the row (derive_seed(42, row)), so every
   row of every method uses the same RNG stream as the B5 EGC row of that image (checked by gate G3).

6. Claims (paired over the images both rows finished; conventions of tools/eval/claims_registered.py: per-image AUC,
   paired geometric-mean L2 ratio, median paired LPIPS difference, image bootstrap B = 10000 with seed 0, one-sided
   Wilcoxon signed-rank, Holm within each family, alpha 0.05).
   - A1 ambient block (Holm, m = 3; non-targeted, every victim): L2@10k ratio EGC / LGC_RC < 1 and upper 95 % bound < 1.
   - A2 naive switch (Holm, m = 3; targeted, every victim): LPIPS-vgg AUC delta (EGC - HT1000) < 0 and upper 95 %
     bound < 0.
   - A3 elliptic metric (Holm, m = 3; targeted, every victim): L2@10k ratio EGC / EGCI < 1 and upper 95 % bound < 1.
   - A4 no targeted cost of the ambient block (interval only; targeted, every victim): L2 AUC ratio EGC / LGC_RC,
     upper 95 % bound <= 1.03.
   - Descriptive (no test, no decision): every other contrast of EGC against each row, both modes: L2 AUC ratio,
     L2@10k ratio, LPIPS-vgg / LPIPS-alex / DISTS / SSIM AUC deltas; and the level of every row (n, mean, median of
     L2, success, LPIPS-vgg, LPIPS-alex, DISTS, SSIM at 1k and 10k).
   - Dev-overlap: every row recomputed without the dev-overlap rows (descriptive; reported as "would any decision
     change").
   - Failure policy: a claim that fails is reported as not confirmed, with its estimate and interval. The method is
     never changed and no ablation cell is re-run selectively.
   - Analysis code: tools/eval/claims_e9.py (sha256 in section 9); the EGC inputs are paper_exports/b5a2/cells and
     paper_exports/b5a2/metrics at this commit.
