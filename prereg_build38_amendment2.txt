6. Metrics. Computed offline from the stored adversarial images (advstore + eval_metrics_offline.py), one
   implementation for all methods.
   - Primary (perceptual): LPIPS-vgg (prereg network), LPIPS-alex (guards against the VGG16-AE / LPIPS-vgg overlap), DISTS.
   - Secondary: SSIM. The EGC gate uses SSIM >= 0.99; this circularity is disclosed.
   - Descriptive: float pixel L2, MS-SSIM, PSNR.
   - Perceptual ASR(q) = mean 1[adv_float AND LPIPS-vgg <= tau_L AND SSIM >= tau_S].
     - NT: (tau_L, tau_S) = (0.05, 0.99).
     - T: (0.3, 0.75).
   - AUC = per-image mean over budgets 500 / 1k / 2.5k / 5k / 10k (log for L2, linear for LPIPS / DISTS).
